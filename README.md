## Код

| Каталог | Призначення |
| --- | --- |
| `diploma_client` | Клієнтський Spring Boot застосунок, автентифікація та керування резервними копіями |
| `diploma_client/frontend` | Вебінтерфейс React і TypeScript |
| `diploma_server` | Сервер зберігання резервних копій локально та в AWS S3 |

Технології: Java, Kotlin, Spring Boot, OpenFeign, React, TypeScript, Web3, AWS S3, Gradle.

Код збережено зі старими залежностями та локальними шляхами. Збірку й запуск під час упорядкування не перевіряли.
